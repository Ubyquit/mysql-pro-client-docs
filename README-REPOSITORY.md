# MySQL Pro Client — Public Documentation Repository

This repository contains the public GitHub/Marketplace documentation and screenshots for **MySQL Pro Client 2.5.1**.

## Current release

- Stable version: **2.5.1**
- Release focus: ER Diagram group-control UX and layout workflow
- Main documentation: `README.md` and `docs/`
- Release history: `CHANGELOG.md` and `RELEASE-*.md`
- Public screenshots: `images/screenshots/`

## 2.5.x highlights

- ER Diagram relationship routing: Orthogonal, Straight and Curved.
- Visual ER Groups with local-only metadata.
- Global and per-group Automatic, Horizontal, Vertical and Grid layouts.
- Elastic group containers and Fit Group to Contents.
- Group-header dragging, containment and collision-aware Auto Layout.
- Improved self-referencing relationship routing.
- 2.5.1 group toolbar/iconography refinement.

The public documentation repository does not need to contain the extension source code. Keep product source/release packaging in the main development repository and publish only documentation/assets intended for users here.
