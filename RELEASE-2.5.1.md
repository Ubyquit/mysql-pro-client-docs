# MySQL Pro Client 2.5.1

## Group controls UX update

Version 2.5.1 is a focused Marketplace update for the ER Diagram group controls.

### Highlights

- Visibility now uses open/closed eye icons.
- Collapse/expand keeps the familiar container metaphor with clearer state.
- Arrange is now a split control: the main action runs the selected layout and the attached dropdown chooses Automatic, Horizontal, Vertical or Grid.
- The Arrange icon and label update to match the selected mode.
- Fit Group to Contents now uses four inward arrows so its purpose is visible without relying on the tooltip.
- Controls inherit VS Code theme colors and include improved accessibility labels.

### Compatibility

This update preserves all 2.5.0 ER Diagram behavior, including elastic groups, group containment, global/group layout modes, Fit Group to Contents, group dragging, Auto Layout and self-referencing relationship routing.
