- `SCHEMA-COMPARE.md` — comparación Reference → Target.

- `BACKUP-RESTORE.md` — mysqldump/mysql y seguridad.
- `SECURITY.md` — modelo de seguridad del cliente.
- `KEYBOARD-SHORTCUTS.md` — atajos y Command Palette.
