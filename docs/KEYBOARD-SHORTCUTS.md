# Keyboard Shortcuts

## Atajos registrados

| Acción | Windows / Linux | macOS |
|---|---|---|
| Run Query | `Ctrl + Enter` | `Cmd + Enter` |
| Run All Queries | `Ctrl + Shift + Enter` | `Cmd + Shift + Enter` |

## Command Palette

Escribe `MySQL:` para descubrir comandos como:

- Add Connection;
- Connect;
- New SQL Query;
- Run Query;
- Run All Queries;
- Visual EXPLAIN;
- Select Editor Connection;
- Select Active Database;
- Generate ER Diagram;
- Preview ER Diagram from SQL;
- Open Live ER Preview from SQL;
- Query History;
- Saved Queries;
- Show Logs.

Los comandos contextuales de tablas, databases y routines también aparecen al hacer clic derecho en el Explorer.
